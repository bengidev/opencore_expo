# OpenCore

OpenCore is a mobile AI chatbot for Android and iOS, built with Expo and React Native.

The app opens on an onboarding screen. Get started replaces the intro with the super-chat conversation at `/super-chat`. Messages stay on the device for now. Assistant replies are local until a model provider is connected. This client does not load provider credentials. Expo embeds `EXPO_PUBLIC_` values in app bundles, so keep provider secrets on a server.

## Flow

- `/` is the onboarding screen.
- Get started opens `/super-chat` directly. The route renders the `src/super-chat/` module.
- `/home` is a separate landing screen with the greeting, suggestion cards, and the shared super-chat composer. Open it at `/home` (or `opencore://home`). Sending from Home opens `/super-chat` with the message seeded; New chat opens `/super-chat` with only the assistant greeting.
- On `/super-chat`, the back affordance is labelled Home when Home is the previous screen.

Get started deliberately skips Home. That is the documented flow, not a routing bug.

## Requirements

- Node.js 20 or newer
- npm
- [Expo Go](https://expo.dev/go) on a phone, or an Android emulator / iOS Simulator

## Run

```bash
npm install
npx expo start
```

Then press `a` for Android or `i` for iOS. The same project also runs on the web with `npx expo start --web`.

Native `ios/` and `android/` folders are generated by Expo and are not committed. Configure native behavior in `app.json`.

## Scripts

| Command | Purpose |
| --- | --- |
| `npm start` | Start the Expo dev server |
| `npm run android` | Open the app on Android |
| `npm run ios` | Open the app on iOS |
| `npm run web` | Open the app in a browser |
| `npm run lint` | Lint the project |
| `npx tsc --noEmit` | Typecheck |

## Project layout

- `src/app/` — screens and navigation (Expo Router)
- `src/onboarding/` — onboarding screen parts
- `src/home/` — suggestion landing screen and shared composer inputs
- `src/super-chat/` — conversation screen, message list, shared composer, and chat state
- `src/components/` — UI that is not a route
- `src/constants/` — theme tokens
- `assets/` — app icon and splash artwork
